# ABC College Complete Website

## Included
Home, About Us, Academics, Programs, Departments, Admissions, Campus Facilities, Sports, Cafeteria, Classrooms, Hostel, Library, Placements, Student Life, News & Events, Contact, Student Login modal, Apply Now modal, search overlay, responsive mobile navigation and interactive program filters. The program catalogue includes undergraduate, postgraduate, engineering, business and science options.

The Student Registration section saves records in the current browser using local storage and can export them as `students.csv`. `data/students.csv` is a blank CSV template. This static-site demo does not save records to that template or share them across users/devices; connect a server-side database and authentication before using real student data.

## Run
Open `index.html` in Chrome or use VS Code Live Server.

## Production
Replace demo college details and remote Unsplash images with your own licensed assets. Connect admissions, login, contact forms, results/attendance and admin features to your PHP/MySQL or Node/Express backend.
